# llm_health.assessment_v2

Repackaged `health-assessment-v2` analytics/dashboard code distributed inside `llm-health`.

This module contains code only. It does not include raw PDFs, Apple Health exports, generated
DuckDB/Parquet data, canonical CSVs, source file paths, legal names, or private health documents.
Install `llm-health[v2]` for the optional analytics/UI dependencies.
